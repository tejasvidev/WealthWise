# WealthWise — AI Architecture

**Document Version:** 1.0  
**Status:** Architecture Definition  
**Project Type:** Major Project  
**Product:** WealthWise  
**Technology Direction:** MERN + Generative AI  
**AI Role:** Financial Interpretation, Explanation & Decision Support

---

# 1. Purpose

This document defines the Artificial Intelligence architecture of WealthWise.

The purpose is to establish:

- where AI is used,
- where AI is explicitly not used,
- how financial context is prepared,
- how prompts are constructed,
- how the AI interacts with deterministic financial services,
- how hallucinations are reduced,
- how AI-generated recommendations are grounded,
- how conversational financial assistance works,
- how scenarios interact with AI,
- how AI failures are handled,
- and how the system remains trustworthy.

The central architectural principle is:

> **AI interprets financial intelligence; it does not become the source of financial truth.**

95. Data Flow Invariants

The following invariants must hold.

Invariant 1

Transactions are the source of truth for transaction-derived spending.

Invariant 2

AI cannot modify financial state directly.

Invariant 3

Scenario calculations do not modify actual transactions.

Invariant 4

Derived data can be recalculated.

Invariant 5

Every financial data flow is user-scoped.

Invariant 6

AI context is derived from validated application data.

Invariant 7

A recommendation does not imply that an action has occurred.
